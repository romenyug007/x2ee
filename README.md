# Автомонополист — онлайн-версия

Игра для 2–6 человек из любых городов. Один человек создаёт комнату, остальные заходят по ссылке или коду из четырёх букв. Все правила, таймеры, займы и гонки работают на сервере, поэтому смухлевать с браузера нельзя.

Внешних библиотек нет: нужен только Node.js 20 или новее.

## Запуск на своём компьютере (проверка)
```
npm start
```
Откройте http://localhost:3000, нажмите «Создать комнату», откройте вторую вкладку и войдите по коду. Чтобы друзья из интернета зашли к вам домой, нужен хостинг (ниже).

## Вариант 1. Render (проще всего, без командной строки)
1. Создайте репозиторий на github.com и загрузите в него все файлы этой папки.
2. На render.com выберите New → Web Service → подключите репозиторий.
3. Runtime: Node. Build Command: `echo ok`. Start Command: `node server.js`.
4. План: Free для теста (сервис засыпает при простое и просыпается примерно за минуту) или Starter (около 7 $ в месяц, не засыпает). Проверьте цены на сайте Render.
5. Через пару минут Render выдаст адрес вида `https://avtomonopolist.onrender.com`. Откройте его, создайте комнату и отправьте друзьям ссылку из лобби.

## Вариант 2. Свой сервер (VPS)
На обычном виртуальном сервере с Ubuntu (2 ядра и 4 ГБ хватит с запасом):
```
sudo apt install -y docker.io
git clone <ваш-репозиторий> && cd <папка>
sudo docker build -t avtomonopolist .
sudo docker run -d --restart=always -p 80:3000 --name am avtomonopolist
```
Для адреса с https поставьте перед сервером Caddy или nginx и привяжите домен. Тогда игра откроется по адресу вашего домена.

## Как играть
Создатель комнаты выбирает цель (30 000, 50 000 или 100 000 €) и нажимает «Начать игру». Ходит один игрок, остальные видят все действия, кубики и таймеры. Ссылка из лобби работает как приглашение. Если вы закрыли вкладку, откройте ту же ссылку: вы вернётесь в игру на то же место. Если игрок молчит, сервер сам делает ход (шаг на одну клетку и такси на самой дорогой машине).

## Что важно знать
- Комнаты хранятся в памяти сервера. Если сервер перезапустится, текущие партии пропадут. На бесплатном тарифе Render это бывает.
- Пустые комнаты удаляются через 6 часов без активности. Одновременно может быть до 300 комнат (число меняется в `server.js`).
- Тесты: `npm test` (52 проверки правил и сервера).
- Правки интерфейса: меняйте `client.src.html` и запускайте `npm run build`, он пересоберёт `public/index.html`.

## Файлы
- `server.js` — сервер (комнаты, таймеры, рассылка состояния).
- `avtomonopolist-engine.js` — правила игры.
- `avtomonopolist-cards.json` — все карты в евро.
- `client.src.html`, `public/index.html` — интерфейс (исходник и сборка).
- `avtomonopolist-rules.md` — описание правил.
